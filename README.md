# python-data-cleaning
Data cleaning project using Python and pandas

### Description
This project focuses on cleaning and preparing raw sales data using Python and pandas.  
The goal is to improve data quality before analysis.

### Data cleaning steps:
- Removed duplicate order IDs
- Removed rows with outliers in total_price (above 800)
- Removed rows with missing product_list values
- Converted and standardized order_date format
- Removed invalid dates

### Tools used
- Python
- pandas
- CSV handling

### Output
The cleaned dataset is saved as a new CSV file using Python.
